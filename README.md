# GameZone Frontend - Gaming Portal

Frontend-only React/Vite gaming portal with a game catalog and community management dashboard.

## Installation

Install all required dependencies:

```bash
npm install
```

## Build

Build the application for production deployment:

```bash
npm run build
```

## Run

Start the local development server:

```bash
npm run dev
```

The application will be accessible at `http://localhost:5173`.

## Testing

Run unit test suite and generate coverage reports:

```bash
npm test
npm run coverage
```
